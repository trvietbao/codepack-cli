# Security Policy

## Supported Versions

Only the latest released version receives active security patches and updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data exposure issue in `codepack-cli`, please report it privately:

1. **Email**: Send details to `trvietbao@gmail.com` with the subject prefix `[SECURITY]`.
2. **Details**: Include reproduction steps, sample inputs, and affected environments.
3. **Response Time**: We aim to acknowledge receipt within 48 hours and provide a fix or mitigation plan within 7 business days.

Please do not open public issues discussing potential security vulnerabilities before a patch is released.
